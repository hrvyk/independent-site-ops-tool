# 獨立站營運工具

這是一套為外貿獨立站日常營運設計的內部工具，主要用來處理報價、物流、時間協作與基礎換算等高頻工作。工具目前以靜態網頁形式運行，適合個人或小團隊快速使用，也方便後續根據新的貨代報價表、營運流程和實際業務需求持續迭代。

## 核心功能

- 價格折算：根據供應商 RMB 成本、即時 USD/CNY 匯率、平台費與多組加價比例，快速計算獨立站建議售價。
- 盈利修正報價：在產品報價低於成本或利潤不足時，協助把差額合理分攤到運費或客製費用中，避免最終報價虧損。
- 單位與體積重換算：支援公分轉英吋，以及依照 `/5000` 或 `/6000` 公式計算體積重。
- 物流報價對比：支援 DHL、UPS、FedEx、空派、海派等渠道的運費、時效與風險權重比較，並可根據貨代報價表匹配可用價格。
- 貨代報價表匯入：可上傳新的 `.xlsx` 報價表，自動讀取並刷新貨代資料，方便應對週期性價格調整。
- 世界時間：可新增主要國家和城市，實時顯示不同時區時間，協助跨國客戶溝通與排程。
- 日月主題：提供 V1 亮色方案與 V2.1 暗黑方案，便於不同使用場景下快速切換。

## 適用場景

- 外貿獨立站產品定價
- 供應商 RMB 報價轉美元售價
- 物流方案初步比較
- 貨代報價表週期性更新
- 跨時區客戶溝通
- 小團隊內部營運效率提升

## 目前狀態

本專案目前為 V2.1 個人工具版本，已完成台灣繁體中文化，並透過公開 GitHub repository 與 GitHub Pages 部署。工具目前不設帳戶與登入功能。
